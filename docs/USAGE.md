# 地震3Dビューアー 操作ガイド — 2026.09.27-rc.8

## 開く
GitHubのReleasesから `index.html` をダウンロードし、Chromeで開きます。GitHubのファイル表示画面ではアプリは動きません。

配布フォルダーの `index.html` は単体で開けます。初期表示は内蔵の2025年・世界M4.5以上8,556件（2026-09-26取得）。保存データの表示は通信不要です。

## 最新情報を取得する
1. 上部の **データ（取得・保存）** を押す。
2. **最新24時間／最新7日／最新30日** を選び、最小マグニチュードを指定する（初期4.5）。
3. **取得して切替** を押す。この瞬間の時刻を終了に固定し、全世界のearthquakeを取得する。終了時刻は含まない。UTC表記。
4. 原本の件数・ハッシュを確認できた場合だけ切り替わる。進捗・キャンセル・再試行が使える。失敗・中止なら元の表示を保持する。

自動更新・常時ポーリングはしません。USGSカタログは後から改訂されます。取得記録は原本JSONとともに保存してください。最新データの件数は取得時点次第です。

## 過去の期間を取得する
開始・終了欄へ**UTC日時**を入力し、最小Mを指定して「取得して切替」。入力を変更するとプリセットから任意期間へ切り替わります。
例：2024-02-28 00:00以上〜2024-03-02 00:00未満、M4.5以上。今回の実取得では61件（2月44件・3月17件）。元の2025年データは「内蔵の2025年保存版に戻す」で再取得なしに戻せます。

1回の取得は3660日以内、10万件まで。USGSの1応答2万件を超える場合は道具が期間を分割します。原本100MiB・256リクエスト・1要求60秒の制限があります。大きすぎる場合は期間を分けるか最小Mを上げてください。途中の一部だけを成功データにはしません。

## 保存してオフラインで再び開く
**データを保存 → JSONを保存/出力**。単独HTMLならJSONをダウンロードできます。
DSHプレビュー内はブラウザーのsandboxにより直接保存が拒否されるため、表示されたJSONを**全選択→コピー**してテキストファイル（`.json`）へ保存してください。大きい場合は「大きなJSONを表示」を明示的に押してからコピーします。あるいはindex.htmlをダウンロードし、単独ブラウザーで開いて取得・保存します。「保存完了」は断言しません。

**保存データを開く**のファイル選択、またはJSON貼付→読込で復元します。USGS原本bytes・取得URL・取得日時・SHA-256・問い合わせ条件を含む取得bundleを検査し、改変・欠落があれば拒否します。読込上限160MiB、10万件、3660日。読み込み後は新しいデータの期間に月・再生・一覧が追従します。

USGSの通常GeoJSONも読み込めます。この場合は**ローカルGeoJSON・取得日時不明**と表示し、全世界を取得し切った証明とは扱いません。取得条件は推定せず、実際の観測期間とMを使います。元ファイルはそのまま保存できます。

未保存データを切り替える場合は、JSONを取り出す／そのまま切り替える／キャンセルを選べます。コピー用JSONは切替後も残します。取得URLや各原本hashは **ヘルプ → データと出典** で確認できます。

## まず日本周辺の深い地震を探す

1. 左の検索に「日本」や「東北」を入力し、候補を選びます。地域プリセット「日本周辺」でも絞れます。
2. 「深い（300km以上）」を押します。適用条件のチップと一覧件数が変わります。
3. 一覧を「深い順」にし、行を選びます。地球儀が対象へ移り、日時・位置・深さ・M・出典を表示します。地球儀の点からも選べます。選択中の地震は、通常の点の深さ配色と区別する専用の赤いマーカーで示します。
4. 「表示設定」で「震源表示」に切り替えます。表面を非表示にすると内部の点が見えます。必要なら深さ倍率を変え、比較後は「等倍」に戻します。現在の表示モードと倍率はヘッダーに常時表示します。
5. 条件チップの解除か「全条件リセット」で絞り込みを戻します。表示モード・地図・倍率は別設定です。

国名は日本語・英語、USGS IDと原文地名の一部でも検索できます。国・地方の候補は概略矩形です。市町村・住所の網羅検索や国境内判定ではありません。日付変更線を跨ぐ範囲は西端の経度が東端より大きくなります。

## 地図と裏側の点

初期値は **地表＋海底地形（陰影）**。地表だけ、地図なしにも切り替えられます。地図を表示中は裏半球の点を描画・選択から除外します。回転すると手前の対象が変わります。

ヘッダーの「絞り込み対象」は全世界の条件該当数、「手前半球の対象件数」は現在の向きで手前にある数です。後者は点の重なりやパネルによる遮蔽を差し引いた画素数ではありません。一覧とCSVは裏側も含む絞り込み対象の全件です。

表面OFF・透明度0・地図なしでは全周の点を表示し、内部を観察できます。地図の陰影はNASA/GEBCOの2004年背景画像で、2025年の観測画像や数値の海底標高モデルではありません。地震の深さはUSGS原本のkm値です。

## 時間を比べる

下の「時間の詳細」を開き、月の棒を押すとその1か月だけ表示します。前月・翌月、開始日以上〜終了日未満のUTC日付範囲も使えます。終了日に含めたい日の翌日を指定します。

日付スライダーと再生は「累積」（現在のデータ開始からカーソル区間まで）か「一定期間」（直近1・7・30日）。データ開始を基準に日単位で進み、最終区間はデータ終了までに切り詰めます。速度は1・7・30日/秒。停止・最初へ・時間だけリセットを使えます。月別集計は検索・地域・深さ・Mに一致する全期間を示し、選択期間の件数・最大M・深さ範囲は別表示です。

## CSVと設定を保存する

「ヘルプ・データ/保存」を開きます。CSVは現在の検索・地域・深さ・M・期間に一致する全件を、一覧と同じ順で生成します。1ページ分だけの出力ではありません。列は `id,time_utc,longitude,latitude,depth_km,magnitude,place,source_url`。

CSVや設定JSONを生成し「全選択」、通常のコピー操作でテキストファイルへ保存します。DSH iframeのクリップボード権限やダウンロード許可には依存しません。設定を戻すときはJSON欄へ貼り付けて復元します。再生は停止状態で戻ります。元データのハッシュが違う設定や無効な値、UTF-8で64KiBを超える入力は拒否し、適用中の状態を保持します。

ヘルプはEscapeで閉じられ、フォーカスが戻ります。狭い画面では上部の「検索・絞り込み」「一覧・詳細」でパネルを開閉します。表示が混み合ったらパネルを閉じ、時間の詳細も折り畳みます。

## 読み込みに失敗したとき

WebGLを使えない場合は、その旨を表示します。地図だけの失敗なら点を維持し、「地図を再読み込み」で元の地図を再試行します。データを読めない場合は開始せず、架空の点で埋めません。DSHで古い版が残る場合はFilesの再読み込みを使います。

この版で実施したのはLinuxのGoogle Chrome（隔離試験はSwiftShader）、既存DSHのsandbox iframe、390px幅・デスクトップ幅の検査です。Safari/Firefox、実スマートフォン、長時間利用、FPS・GPU性能の計測は未実施。地震や被害の予測、震度表示は行いません。
