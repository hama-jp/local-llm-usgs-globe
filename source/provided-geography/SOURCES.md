# オフライン地名候補用の原資料
Natural Earth公式配布案内・作者管理GeoJSON・利用条件を未加工で保存。NAME_JA / NAME_EN / ADMIN等とgeometryを参照。国・地域の概略範囲の候補を作るための資料で、地震データではない。小国など未収録の地名もある。住所や全市町村の検索は提供しない。
この資料からの検索索引・経度最短円弧境界・UI候補処理はローカルLLMが実装する。周辺海域を含めて範囲検索する場合は「周辺の矩形範囲」と明記し、国境内の判定と呼ばない。
日本の地方（北海道・東北・関東・中部・近畿/関西・中国地方・四国・九州・沖縄）については、オフライン探索用の概略矩形プリセットを別に用意してよい。行政界そのものではなく探索用範囲であることをUI/出典に明示する。市町村や未収録地域を検索できたように装わない。
